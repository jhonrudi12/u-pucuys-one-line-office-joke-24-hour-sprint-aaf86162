An entry for the [make.fun](https://make.fun/) bounty **"One-Line Office Joke: 24-Hour Sprint"** — one line about office life, under 200 characters, and nothing else.

## The joke

> Our office printer only works when nobody needs it, which technically makes it our most reliable employee.

The setup is the printer that only ever works when nobody needs it — a
specific office detail anyone who has queued behind a jammed printer
recognises. The punchline flips the complaint: by the office's own logic,
that makes it the most reliable employee we have. One sentence, no
explanation needed.

## How it works

`main.py` (Python 3.13) writes the joke — and nothing else — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`, or pass an
output directory as the first argument, e.g. `python3 main.py /tmp/jokes-out`).
It is deterministic, uses no network, and reads no input.

## Run it

```sh
python3 main.py
```
